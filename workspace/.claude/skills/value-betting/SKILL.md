# Поиск ценности (value betting)

1. Собери линию букмекеров на целевые матчи (WebSearch).
2. Оцени вероятность исходов самостоятельно: форма, xG, составы, H2H, мотивация.
3. Сравни свою вероятность P с коэффициентом K букмекера.
4. Value = P × K − 1. Если value > 5% — исход кандидат.
5. Покажи таблицу: матч | исход | K | твоя P | value %.
6. Итог: 1–3 лучшие ставки дня с уровнем уверенности и дисклеймером про риски.
